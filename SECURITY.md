# Security Policy

## Supported Versions

Only the `main` branch (the deployed site) receives security fixes.
`develop` is the integration branch and may contain unreleased changes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's private vulnerability reporting: open the
**Security** tab and choose **Report a vulnerability**. If that option is
missing, the repository owner must enable it in the repository settings
(**Settings → Code security → Private vulnerability reporting**).

## Deployment Policy

Live LLM calls are disabled on the public site; the demo uses recorded runs.
This is the project's intended policy.
